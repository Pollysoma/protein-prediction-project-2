# Split requirements: source notes

Raw extraction from the literature behind [`protocol/04_split_requirements.md`](../../protocol/04_split_requirements.md), which is the document to read first. These notes are the evidence layer: every requirement in the protocol should be traceable to a line here, with a section, table or quote pointer.

| File | Covers |
| --- | --- |
| [`notes/rostlab-core.md`](notes/rostlab-core.md) | ProtTucker/EAT (Heinzinger 2022), goPredSim (Littmann 2021), HFSP (Mahlich 2018) |
| [`notes/contrasted-ankh-eatcode.md`](notes/contrasted-ankh-eatcode.md) | ContrasTED (Miller 2026), Ankh, and what the EAT reference code actually does |
| [`notes/external-split-literature.md`](notes/external-split-literature.md) | Homology-aware partitioning, redundancy-reduction tools, leakage critiques, calibration methods |
| [`notes/ec-split-requirements.md`](notes/ec-split-requirements.md) | EC labels, evidence codes, multi-label and incomplete EC, published EC benchmark splits |

The notes were produced by four separate readings and are deliberately verbose. They disagree with each other in places; where they do, the protocol says which reading we follow and why. Two items in the EC notes are marked unverified: the project brief's UniProt 2026_03 counts, and the original supplementary split settings of DeepEC and ECPred.
